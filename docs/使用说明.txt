英语机考模拟器 —— 使用说明
================================================

【第一次运行前，先做这一步（很重要）】
  发布包经 网盘 / 微信 / QQ / 浏览器 下载到电脑后，Windows 会给里面的文件打上"来自 Internet"的
  标记（Mark of the Web）。带这个标记的 exe 运行时，Windows 可能弹蓝框「Windows 已保护你的电脑」，
  部分杀毒软件还会直接拦截甚至删除它。本程序没有病毒（做题不依赖联网、不写系统目录，只在 127.0.0.1
  开一个本机端口；只有主动查在线词典时才联网，详见文末【技术信息】），这只是"没有购买商业代码签名证书"带来的信誉提示。
  下面两种做法任选一种，做一次就行：

    做法 A（推荐，解压前做）
      右键你下载到的那个 .zip → 属性 → 在下方勾选「解除锁定」→ 确定，然后再解压。

    做法 B（已经解压了）
      双击本文件夹里的「解除锁定.bat」，等它显示 DONE 即可。
      也可以只处理程序本身：右键 英语机考模拟器.exe → 属性 → 勾「解除锁定」→ 确定。

    万一还是弹出蓝框 → 点「更多信息」→「仍要运行」。
    万一被杀毒软件拦截/删除 → 把本文件夹加入杀毒软件信任，或改用「备用启动.bat」启动（不需要 exe）。

【怎么用】三步
  1. 双击 英语机考模拟器.exe（会出现一个深色小窗口）
  2. 点窗口上的「打开练习页面」——浏览器会打开练习页面；
     把 .zip 题包拖进首页的导入框，或点它选择文件（例如 剑17_Test1_题包.zip）
  3. 回到题库列表点「开始练习」即可

【v2.0 新增功能一览】
  · 未完成练习中心：首页顶部会出现「继续上次练习」，显示范围、阶段、已答数量、剩余时间和
    上次作答时间；可继续、重新开始或放弃进度。题库条目有进度时主按钮变成「继续」。
    练习模式听力不限时也能恢复（显示「不限时」）。
  · 交卷前检查：点「交卷」先显示已答/未答/Flag 摘要；点未答题号可直接跳回那道题；
    写作显示每个 Task 的词数与建议最低词数，词数不足只提醒、不阻止交卷。
    时间自动归零仍直接收卷，不弹这个窗口。
  · 写作答卷历史：交卷时自动保存原稿与题目快照；练习记录 →「看详情」→「写作答卷」可查看
    本次正文、判改结果、以及「修改稿与对比」。修改稿单独保存，不会改掉原稿和原场次成绩。
    即使没有配置判改模型，原稿也照样保存。
  · 错题复盘：交卷后自动收录答错和漏答的题；顶部「错题复盘」可按科目/题型/错因/状态/题包筛选，
    可开始 10 题一组的重做。重做只影响复盘数据，不会覆盖正式作答存档。
  · 词汇复习：顶部「词汇复习」分「今日复习 / 自由翻卡 / 全部词句」。今日复习按 3/7/14/30/60/
    120/180 天安排到期；「不认识 / 模糊 / 认识」三档反馈；同词来自精读和精听只算一个复习单位。
    翻面后才显示评分按钮；自由翻卡只浏览、不改进度。
  · 学习分析：Band 趋势（只统计整卷）、正确率趋势（含单篇/单节）、题型正确率（点击条形可跳复盘）、
    写作四维平均、错题状态；图表下都标注了样本范围。
  · 统一搜索：首页右上方搜索框可同时搜题库、练习记录、单词与批注；上下键选择、回车打开、Esc 关闭。
  · 数据管理：一键创建/恢复全量备份（详见下面【备份与恢复】）。

【关于那个深色小窗口】
  · 它是程序的"状态面板"：显示 已就绪 时说明一切正常，把它放着不用管
  · 它不会自己打开浏览器，只有点「打开练习页面」才会打开
  · 点完按钮后看状态文字就知道结果：
      「运行中，页面已在浏览器打开」= 浏览器确实回来取过页面了，是真打开了；
      「没能自动打开浏览器」= 没打开，窗口会告诉你下一步怎么办（见下方常见问题）
  · 浏览器不小心关掉了 → 再点一次「打开练习页面」就能重新打开
  · 关闭这个小窗口 = 退出整个程序（再次双击 exe 即可重新启动）
  · 再次双击 exe 不会开第二个程序：会把已有窗口带到前台，并顺手帮你打开练习页面

【题包从哪来】
  题包是 .zip 文件，里面含听力音频、阅读文章、写作题目和标准答案。
  本模拟器不带题包，请使用你手上的题包文件（同一目录下如有「题包」文件夹可直接取用）。

【精读功能】
  · 入口：交卷后的成绩单上有蓝色「精读」按钮（多篇阅读会先让你选哪一篇）；
    首页「精读记录」区列出所有做过精读的篇目，点进去可以回看、继续添加或删除批注
  · 用法：在精读界面的文章里划选文字，弹出「单词 / 句子 / 查词」三个按钮——
    选「单词」自动收敛到这个词（蓝色高亮），选「句子」自动扩到整句（琥珀色高亮）；
    靠近文字那一侧的边栏会出现同色批注框，在里面写笔记，✕ 收起成小色点，框内可删除
  · 查词典：点顶栏「查词典」打开右侧栏，或划词后点「查词」直接查询；
    侧栏显示音标、词性、英文释义和例句，也可以一键打开 Cambridge 英中或英英词典（需要联网）
  · 翻卡复习：首页可直接翻最近收录的 10 个单词，点卡片看背面释义、批注和例句；
    点「更多」进入词汇中心，可翻卡、列表浏览，并按间隔复习计划复习，从词条详情「跳转到原文」
  · 数据：每篇精读是 精读记录\ 下的一个独立文件，词汇句子册是 词汇句子册.json，
    每次精读都会自动保存并更新这两个地方

【精听功能】
  · 入口：听力交卷后的成绩单上有深青色「精听」按钮（整套听力会先让你选哪一节）；
    首页「精听训练」区列出练过的篇目，也可以从那里直接选任意一套题的任意一节开始
  · 第一次练某一篇时，程序会自动把音频切成句子（本地静音检测，不联网）；
    界面会提示你「粘贴本篇听力原文」——题包里没有原文，粘贴一次后自动逐句对齐到音频，
    之后听写打分、字幕、点词查释义这些功能才有文本依据；不粘贴也能用重听/变速/AB循环/跟读
  · 中栏是句子卡片流：初始只显示序号（文本遮盖），可重听 / 显示文本 / 标记难点；
    听写提交后逐词对比（错词红、漏词虚线空位、多写删除线），再选一个错因标签归档；
    全对或手动标"过了"句子收起成绿色一行。点单词弹释义气泡（需已配置文本模型），可加入生词本
  · 底栏播放器：播放/暂停、上下句、5 档变速直点、AB 循环（进度条高亮区间）、
    句子刻度线悬停看句首词、点击跳句；快捷键：空格=播放/暂停，R=重听当前句，←→=切句
  · 左栏：本篇/全部生词（点来源跳回那句）、薄弱句清单（重听≥3 或错≥2 自动聚合，可只刷这些句）；
    右栏：重听热力色块 + 错因分布，点统计项可筛选中栏只显示相关句子
  · 泛听模式：收起全部交互，连续播放 + 完整字幕，适合第一遍摸底和二刷检验
  · 数据：每篇精听是 精听记录\ 下的独立文件，生词汇总在 生词本.json，跟读录音也在本地文件夹

【你的数据存在哪】
  题库、听力音频、练习记录都保存在本程序所在文件夹下的几个文件夹里（v3.4 起）：
    导入题目\   —— 数据\tests.json（解析后的题库）、媒体\（每套题的音频与题图）、
                  题包\（每次导入时留一份 zip 原件）
    做题记录\   —— records.json（全部练习记录）
                  写作\<记录id>.json（每场写作的原稿、题目快照与修改稿；v2.0 新增）
                  学习数据.json（错题复盘、词汇复习进度、已收录记录；v2.0 新增）
    精读记录\   —— 每篇阅读的精读一个 <题包id>__p<篇号>.json（划出的单词/句子高亮与批注），
                  以及 词汇句子册.json（所有精读写下的单词/句子汇总册）
    精听记录\   —— 每篇听力一个 <题包id>__s<节号>.json（句子切分、对齐的原文、听写/重听统计），
                  以及 生词本.json（精听时点出来的生词汇总）；跟读录音在 导入题目\媒体\ 下
  · 每次导入题包、交卷出成绩都会自动写进这些文件夹；打开页面时会从文件夹恢复，
    所以换浏览器、清浏览器数据、端口变化都不再丢题库、成绩、写作答卷和学习数据
  · 把整个程序文件夹复制到别的电脑，题库和成绩会一起带走
  · 浏览器里仍存有一份工作缓存（localStorage / IndexedDB），页面离线打开也能用
  · 未完成练习的作答与倒计时只保存在浏览器；换端口/换浏览器不会自动带过去，
    需要还原时请用「数据管理 → 备份/恢复」（备份里包含 active-session 与各科作答）
  · 笔记、高亮、写作草稿等作答过程数据，以及 AI 模型配置（Base URL / API Key）
    仍只保存在浏览器本地，不进这些文件夹
  · 若程序目录不可写，会自动退回旧行为：只保存在浏览器本地
  · 用「备用启动.bat」（PowerShell 版）启动时没有文件夹同步功能，数据只保存在浏览器本地

【备份与恢复】
  入口：首页右上角「数据管理」。
  · 创建备份：勾选「包含音频、题图和录音」会生成含媒体的完整包（文件较大）；不勾则体积小，
    只含题库、成绩、写作、学习数据、精读/精听、词汇、未完成练习和界面设置。
    备份不包含模型配置与任何 API Key，可以放心转存。
  · 恢复前会先预检：检查格式版本、JSON 是否可读、媒体路径是否合法，并显示各模块数量。
    预检不通过会列原因并停止，不会写坏当前数据。
  · 合并恢复（默认）：只新增备份里独有、当前没有的内容；同 ID 冲突默认保留当前，
    也可以选「冲突使用备份」。合并不会删除当前独有的数据。
  · 完整替换：清空本应用的题库/成绩/写作/精读/精听/词汇/复盘/未完成练习后写入备份；
    执行前会强制先创建一份含媒体的当前备份并开始下载，作为回滚保障。
    如果备份包不含媒体，替换后当前媒体会被移除，确认页会明确警告。
  · 恢复完成后会等镜像写入本地文件夹结束再提示；如果同步失败，本地恢复结果仍保留，
    稍后刷新重试即可，不会再用旧文件覆盖。

【删除数据会发生什么】
  · 首页「放弃进度」：只删这套题当前的作答、作文、笔记、高亮和计时；
    已交卷的练习记录、写作答卷、复盘、词汇和精读/精听都保留。
  · 删除一条练习记录：删除该记录与同场的写作答卷正文；复盘引用与词汇复习进度保留。
  · 清空练习记录：清空全部记录与写作答卷正文；复盘与词汇复习进度保留。
  · 删除题包：删除该套题当前进度、音频与题图；已交卷的历史、写作题目快照、
    复盘和词汇都保留（复盘里会标记「题包已删除」，重做按钮禁用并说明原因）。
  · 所有删除都有二次确认，确认框会列出影响范围。

【常见问题】
  · 双击 exe 时出现蓝色「Windows 已保护你的电脑」→ 见开头【第一次运行前】。快速办法：
    右键 exe → 属性 → 勾「解除锁定」→ 确定；或直接点蓝框里的「更多信息」→「仍要运行」
  · 杀毒软件报警/删除了 exe → 把本文件夹加入信任；急用可双击「备用启动.bat」（PowerShell 版启动器，
    不需要 exe），或把整个发布包复制到别的电脑使用。不放心可用下面命令核对文件是否被改动：
    certutil -hashfile 英语机考模拟器.exe SHA256
  · 导入时提示「缺用户自备文件 xxx.mp3」→ 该题包不含音频，不影响做题，只是听力没声音
  · 页面样式异常/看不到新内容 → 按 Ctrl+F5 强制刷新一次
  · 点「打开练习页面」后显示「没能自动打开浏览器」→ 地址已经复制到剪贴板了，直接到浏览器
    地址栏粘贴（Ctrl+V）回车即可；程序目录下若生成了「打开练习页面.bat」，双击它也能打开；
    窗口上的「复制地址到剪贴板」按钮可以再复制一次
  · 窗口上显示黄色「本程序正以『受限权限』运行」→ 说明这个 exe 文件本身被打上了
    「低完整性级别(Low)」标签（多由自动化工具/沙箱写文件造成，或被安全软件隔离过）。
    带这个标签的 exe 双击也会以低权限运行，而低权限进程不允许调起你的浏览器，所以点按钮
    只会把浏览器窗口带到前台、标签页打不开；日志里对应一行「完整性级别: Low(4096)」。
    解决（在该目录打开 PowerShell 或命令提示符，执行一次）：
        icacls "英语机考模拟器.exe" /setintegritylevel Medium
    然后重新双击 exe，日志里应显示「完整性级别: Medium(8192)」。
    （用「启动器源码\build-launcher.ps1」重新编译时，脚本会自动做这一步）
  · 窗口上显示红色「没能在你的电脑上启动服务」→ 多半是安全软件拦截，把本程序加入信任后重试，
    可点「查看日志」看详细原因
  · 查看 PDF 答案解析需要 Chrome / Edge 94 或更高版本；听力、阅读、写作主流程 Chrome / Edge 89 即可
  · 想换端口 → 命令行运行： 英语机考模拟器.exe --port=18000（数据在文件夹里，换端口不影响题库与成绩）
  · 怀念旧的黑色控制台界面 → 命令行运行： 英语机考模拟器.exe --console

【技术信息】
  · 单文件 exe，内嵌了整个网页应用，无需安装 Node/npm；做题和本地数据不依赖联网，在线词典除外
  · 自检： 英语机考模拟器.exe --selftest（会打印完整性级别、内嵌资源数、HTTP 各项检查；
    自检也覆盖新增的写作答卷 /api/writing 与学习数据 /api/store/learning 接口，
    其中写作只用 _selftest 记录，学习数据只读并用非法版本验证拒绝，不动真实用户数据）
  · 新增接口（v2.0）：GET /api/writing（答卷 id 列表）、GET/PUT/DELETE /api/writing/<id>、
    GET/PUT /api/store/learning；写入均为原子写，id 走与题包相同的路径安全校验
  · 打开浏览器是「多种方式依次尝试 + 真验证」（v3.2 起）：系统默认关联 → 默认浏览器程序 →
    rundll32 → cmd start → 常见浏览器 exe → explorer；每种方式都用"本机服务器有没有收到页面请求"
    来判定，只有真收到请求才算成功，所以状态文字不会骗人
  · 打开浏览器时只会"把浏览器窗口请到前台"，不会改变它的大小、位置或最大化状态；
    只有当浏览器窗口处于最小化时，才会把它还原回来（v3.2.1 起；更早版本会把最大化的
    浏览器窗口擅自变成窗口化并挪一下位置，已修复）
  · 包内辅助文件：「解除锁定.bat」清除"来自 Internet"标记；「备用启动.bat / .ps1」不依赖 exe 的
    PowerShell 启动器（需要完整保留 源码\dist）；「环境自检.bat / .ps1」不启动程序只做环境检查
  · 源码在「源码」文件夹（开发用，需要 Node 20+ 与 pnpm install 才能重新构建）；
    启动器源码在「启动器源码」文件夹：Launcher.cs + build-launcher.ps1（Windows 自带 csc.exe 即可编译）
